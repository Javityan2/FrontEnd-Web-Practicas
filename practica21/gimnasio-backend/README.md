# API del gimnasio

Backend de referencia de la clase, integrado con NestJS, Prisma y MySQL. Sirve el catálogo y las imágenes que consume el panel de la práctica 21.

La configuración y los comandos de ejecución se encuentran en el [README de la práctica](../README.md). Los ejemplos de peticiones están en [peticiones.http](peticiones.http).
