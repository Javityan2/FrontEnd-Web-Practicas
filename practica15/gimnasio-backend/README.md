# Gimnasio Titanes — Backend

Backend proporcionado para la práctica, desarrollado con NestJS, Prisma y MySQL. El frontend utiliza las consultas públicas `GET /clases` y `GET /clases/:id`, junto con las imágenes de `/img/`.

Los datos iniciales incluyen ocho clases y un horario lleno en Fuerza total. La base de datos de esta entrega es `gimnasio_practica15`.

La configuración y los comandos de ejecución se encuentran en el [README de la práctica](../README.md).
